# 要件: ダイビングログの記録・閲覧・編集・削除

関連: [設計](./design.md) / [概要](../00-overview.md) / [写真添付](../photo-attachment/requirements.md) / [ガイドサイン](../guide-signature/requirements.md)

## 概要

1本のダイビングを1件の「ダイビングログ」として記録する。基本情報・環境情報・器材/エア管理・写真・ガイドサインを1つのレコードにまとめて保存し、一覧・詳細・作成・編集・削除ができる。

## 項目定義

| 分類 | 項目 | 必須 | 型 |
| --- | --- | --- | --- |
| 基本情報 | 日付 (date) | ○ | 日付文字列 (YYYY-MM-DD) |
| 基本情報 | 開始時刻 (startTime) | - | 時刻文字列 |
| 基本情報 | ダイビングポイント名 (siteName) | ○ | 文字列 |
| 基本情報 | 最大水深 m (maxDepth) | - | 数値 |
| 基本情報 | 潜水時間 分 (duration) | - | 数値 |
| 環境情報 | 水温 ℃ (waterTemp) | - | 数値 |
| 環境情報 | 透明度 m (visibility) | - | 数値 |
| 環境情報 | 天候 (weather) | - | `sunny` / `cloudy` / `rainy` / `other` |
| 環境情報 | 流れ (current) | - | `none` / `weak` / `moderate` / `strong` |
| 器材・エア | タンク開始圧力 bar (tankStartPressure) | - | 数値 |
| 器材・エア | タンク終了圧力 bar (tankEndPressure) | - | 数値 |
| 器材・エア | ウェイト kg (weight) | - | 数値 |
| 器材・エア | 使用器材 (gear) | - | 文字列 |
| 写真・メモ | バディ名 (buddyName) | - | 文字列 |

## 要件（EARS形式）

### 一覧表示
- REQ-1.1: システムは、保存済みの全ダイビングログを日付の新しい順に一覧表示するものとする。
- REQ-1.2: 保存済みログが0件のとき、システムは一覧の代わりに空状態メッセージ（「まだ記録がありません。」）を表示するものとする。
- REQ-1.3: 一覧の各行には、日付・ダイビングポイント名に加え、値が存在する場合のみ最大水深・潜水時間・写真枚数・サイン済みマークを表示するものとする。
- REQ-1.4: ユーザーが一覧の行を選択したとき、システムは該当ログの詳細画面へ遷移するものとする。

### 新規作成
- REQ-2.1: ユーザーが「新規記録」を選択したとき、システムは全項目が未入力（日付のみ本日日付で初期化）の入力フォームを表示するものとする。
- REQ-2.2: 日付とダイビングポイント名が未入力のとき、システムはフォームの送信を許可しないものとする（HTML必須項目バリデーション）。
- REQ-2.3: ユーザーが入力フォームを送信したとき、システムは新しいダイビングログをローカルデータベースに保存し、作成日時・更新日時を現在時刻で記録するものとする。
- REQ-2.4: 保存が完了したとき、システムは作成されたログの詳細画面へ遷移するものとする。
- REQ-2.5: ユーザーが入力中に「キャンセル」を選択したとき、システムは入力内容を破棄して一覧画面へ戻るものとする。

### 詳細表示
- REQ-3.1: システムは、詳細画面にログの全項目を分類（基本情報／環境情報／器材・エア管理／写真・メモ／ガイドサイン）ごとに表示するものとする。
- REQ-3.2: 値が未入力の項目は、システムは「-」または空扱いとして表示するものとする。
- REQ-3.3: 対象のログが存在しない（削除済みなど）とき、システムは「記録が見つかりませんでした。」を表示するものとする。

### 編集
- REQ-4.1: ユーザーが詳細画面で「編集」を選択したとき、システムは既存の値で初期化された入力フォームを表示するものとする。
- REQ-4.2: ユーザーが編集内容を送信したとき、システムは該当ログを更新し、更新日時を現在時刻で上書きするものとする（作成日時は変更しない）。
- REQ-4.3: 更新が完了したとき、システムは詳細画面へ遷移するものとする。

### 削除
- REQ-5.1: ユーザーが詳細画面で「削除」を選択したとき、システムは削除前に確認ダイアログを表示するものとする。
- REQ-5.2: ユーザーが削除を確定したとき、システムは該当ログおよびそれに紐づく添付（写真・サイン画像）をすべて削除し、一覧画面へ戻るものとする。
- REQ-5.3: ユーザーが確認ダイアログをキャンセルしたとき、システムは何も削除せず詳細画面に留まるものとする。
